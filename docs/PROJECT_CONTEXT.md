# 项目上下文：抖音小游戏找不同

## 当前目标

开发一个抖音小游戏，玩法是“两张卡通图片找不同”。当前阶段先做初版框架，目标是能在抖音开发者工具里导入并跑通核心流程。

## 当前进度

- 已创建原生小游戏入口：`game.js`。
- 已创建小游戏配置：`game.json`，当前为竖屏。
- 已创建开发者工具导入配置：`project.config.json`。
- 已实现 Canvas 渲染、点击输入、关卡状态、差异点命中判断。
- 已生成两组本地卡通占位关卡图片，位于 `assets/`。
- 已接入音频框架，包含背景音乐、命中反馈、通关音效和音乐开关。
- 已打磨界面视觉，当前方向是“游戏 HUD + 对比舞台”：顶部信息条、统一图片舞台、宝石进度、图片内角标、命中标记和通关弹层。
- 已提供关卡配置，位于 `src/levels.js`。

## 核心玩法

1. 加载当前关卡的左右两张图。
2. 玩家点击任意一张图中的不同处。
3. 点击坐标会换算成原图像素坐标。
4. 命中 `diffs` 中配置的差异点后，进度加一，并在两张图对应位置画圈。
5. 找完本关全部差异后显示通关弹层。
6. 通关后可进入下一关，最后一关后回到第一关。

## 本地验证

在项目根目录运行：

```bash
npm run generate:assets
npm run generate:audio
npm run check
```

`npm run generate:assets` 会重新生成占位图片。`npm run generate:audio` 会重新生成原创占位音频。`npm run check` 会做 JavaScript 语法检查。

导入抖音开发者工具后，需要验证：

- 游戏能正常启动，没有控制台报错。
- 两张图正常显示。
- 点击差异点能出现绿色圈并更新进度。
- 重复点击已找到差异点不会重复加分。
- 点击空白处只显示短暂错误反馈。
- 找完全部差异后出现通关弹层。
- 点击“下一关”或“再玩一次”能继续。
- 第一次点击后背景音乐开始播放。
- 找对差异点有积极反馈音，通关有完成音。
- 点击右上角音乐按钮可以开关音乐。
- 顶部进度、底部操作栏和通关弹层在模拟器中布局正常。

## 重要文件

- `README.md`：给人看的项目说明和导入步骤。
- `game.js`：小游戏入口。
- `game.json`：小游戏配置。
- `project.config.json`：抖音开发者工具导入配置。
- `src/Game.js`：游戏主控制器。
- `src/gameState.js`：关卡进度和命中状态。
- `src/renderer.js`：Canvas 布局和绘制。
- `src/input.js`：点击坐标映射。
- `src/audio.js`：背景音乐、音效播放和音乐开关。
- `src/levels.js`：关卡图片与差异点配置。
- `tools/generate-assets.js`：占位图片生成脚本。
- `tools/generate-audio.js`：原创占位音频生成脚本。

## 当前约定

- 这是抖音小游戏，不是普通抖音小程序页面。
- 首版不接入登录、排行榜、广告、云存档、支付。
- 首版图片差异点通过人工配置，不做图片自动识别。
